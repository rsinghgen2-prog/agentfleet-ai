## 🚀 **Clone in Visual Studio Code (30 Seconds)**

### Option 1: VS Code UI (Recommended)

1. **Open VS Code**
2. Press **Ctrl+Shift+P** (or Cmd+Shift+P on Mac)
3. Type: `Git: Clone`
4. Paste: `https://github.com/rsinghgen2-prog/agentfleet-ai.git`
5. Choose folder location
6. Click **"Open"** when prompted

### Option 2: VS Code Terminal

1. **Open VS Code**
2. Press **Ctrl+`** (backtick) to open terminal
3. Run:
```bash
cd Documents  # or wherever you want the project
git clone https://github.com/rsinghgen2-prog/agentfleet-ai.git
cd agentfleet-ai
code .
```

---

## 📦 **Setup & Run (1 Minute)**

After cloning, in VS Code terminal:

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open browser
# Click on: http://localhost:5173
```

## 🆘 **Quick Help**

### Problem: Git not installed
**Download:** https://git-scm.com/downloads

### Problem: Node.js not installed
**Download:** https://nodejs.org/ (version 18+)

### Problem: Port 5173 already in use
```bash
npm run dev -- --port 3000
```

### Problem: npm install fails
```bash
npm cache clean --force
rm -rf node_modules
npm install
```
